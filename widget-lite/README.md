# 바탕화면 위젯 Lite (파일럿)

기존 Electron 위젯(`widget/`, `HPlanWidget.exe` ≈ 70MB)의 저용량 대체 후보다.
크로미엄을 내장하지 않고 윈도우에 이미 있는 **WebView2(엣지)** 를 쓰는 Tauri v2 앱이라
exe 가 수 MB 로 준다. 기능·동작·화면(같은 웹앱 `?w=1&glass=1`)은 기존 위젯과 같게 이식했다.

- exe 이름: `HPlanWidgetLite.exe` · 문서 폴더는 기존과 같은 `문서\H 주요업무현황\`
- 설정: `%APPDATA%\HPlanWidgetLite\widget-state.json` · 로그: `widget-lite-log.txt` (기존 것과 분리)
- 릴리스 태그: `widget-lite-vX.Y.Z` (빌드는 `.github/workflows/widget-lite.yml` 이 자동으로)

## ⚠ 파일럿 기간 규칙

1. **기존 위젯과 둘 중 하나만 켠다** — 둘 다 켜면 윈도우 알림과 자동 백업이 겹친다.
   (백업 파일 이름이 같아 덮어써질 뿐 데이터가 깨지지는 않는다.)
2. `읽어주세요.txt` 는 기존 위젯이 관리한다 — Lite 는 건드리지 않는다.
3. 검증을 통과하고 1~2주 실사용 뒤에 전환을 결정한다. 그 전에는 기존 exe 를 지우지 않는다.

## Electron 판과 다른 점 (알고 쓰기)

- **자리·크기 조정**: 조정 모드(위젯 설정 > 위치·크기 조정)에서 창 안 아무 데나 끌면 이동,
  **가장자리 12px** 을 끌면 크기 조절. (Electron 은 보이지 않는 테두리로 조절했다.)
- **바탕화면 모드 z-순서**: 위젯을 쓰는 동안(전면 창일 때)은 맨 아래로 내리지 않고, 다른 창으로 옮겨 가면
  1.5초 안에 제자리로 내려간다. Electron 판과 같은 규칙이다.
- **네트워크 오류 보기 메뉴 없음** — WebView2 는 요청 단위 훅이 없다. 대신 페이지 무응답 시
  15초 간격 감시가 자동 재접속하고 사유를 `widget-lite-log.txt` 에 남긴다.
- 자동 업데이트는 자기 자신(Lite 릴리스)만 본다. 최신 릴리스가 Electron 판이면
  '확인 실패'로 조용히 넘어간다(정상).

## 첫 빌드에서 확인할 것 (컴파일은 Actions 가 처음 수행한다)

이 소스는 컨테이너 제약(러스트 미제공)으로 **로컬 컴파일 검증 없이** 작성됐다.
`widget-lite/Cargo.toml` 을 올리면 Actions 가 빌드한다. 실패하면 로그의 오류 부분을 그대로 전달할 것.
조정 가능성이 있는 지점(의도적으로 한 곳에 모아 둠):
- `tauri-winrt-notification` 의 `on_activated` 시그니처 (알림 클릭 → 해당 날짜 이동)
- `rfd` 버튼 결과 매칭(`MessageDialogResult::Custom`)
- 트레이/메뉴 빌더의 세부 API 명

## 검증 체크리스트 (waudit 21항목 + Lite 고유)

기본 21항목(기존 위젯과 동일): 표시·투명·유리, 달력 42칸, 팝업/설정/알림/내업무, 필터,
글꼴·크기·투명도 설정, 다크/라이트, 새로고침, 브라우저 열기 …

Lite 고유로 반드시 볼 것:
1. **투명 창 글자 선명도** — ClearType 문제는 윈도우 함정이라 재검증(129~143차와 동일 기준)
2. **배율 다른 보조 모니터**에서 재부팅 반복 → 자리·크기 유지 (log 의 '자리 되돌림' 확인, 160차 함정)
3. 바탕화면 모드: 다른 창 아래 유지 + **입력 가능**(로그인 칸 타이핑) + Win+D 뒤 되살아남
4. 항상 위 모드 전환·유지
5. 조정 모드: 이동·8방향 크기 조절·끝내기 → 잠금
6. 윈도우 알림: 부팅 브리핑(하루 1회)·부름(30초) 표시, **클릭 시 해당 날짜로 이동**
7. 자동 백업: 관리자 로그인 상태에서 `backup\hplan_YYMMDD.json` 생성, 12개 유지
8. 자동 실행: 재부팅 뒤 실행(문서 폴더 경로 등록 확인 — 트레이 > 자동 실행 상태 확인)
9. 자기 업데이트: 버전 올려 릴리스 → '업데이트 확인' → 받아 둠 → 재부팅 교체 / 지금 업데이트
10. 다른 폴더에서 실행 → 문서 폴더 판으로 넘어가며 종료(handOver)
11. 사내망: 로그인·실시간 반영·재접속(와이파이 껐다 켜기)
12. 외부 링크(업무의 링크 아이콘) → 기본 브라우저로 열림
